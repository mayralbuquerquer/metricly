# Gap Analysis — Metricly

A comparação entre o processo atual e o processo desejado permitiu identificar os principais gaps.

| Situação Atual | Gap Identificado | Situação Desejada |
|---|---|---|
| Solicitações por múltiplos canais | Ausência de entrada padronizada | Canal/processo centralizado |
| Nem todas as demandas são registradas | Falta de rastreabilidade | Registro obrigatório |
| Priorização informal | Ausência de critérios objetivos | Priorização padronizada |
| Capacidade percebida informalmente | Baixa visibilidade da carga | Indicadores de carga por responsável |
| Planilha pode ficar desatualizada | Informação pouco confiável | Status centralizado e atualizado |
| Solicitante pergunta sobre andamento | Falta de acompanhamento autônomo | Consulta do status da demanda |
| Conclusão comunicada informalmente | Comunicação inconsistente | Processo padronizado de encerramento |
