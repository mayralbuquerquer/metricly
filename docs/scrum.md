# Planejamento Scrum — Metricly

## MVP

O MVP foi definido com foco nas funcionalidades essenciais para centralização e acompanhamento das demandas:

- cadastro de demandas;
- validação das informações obrigatórias;
- consulta e acompanhamento;
- triagem e priorização;
- atribuição de responsáveis;
- controle de status.

Funcionalidades mais avançadas, como automações de notificações e detecção automática de duplicidades, podem ser evoluções posteriores.

## Sprint 1

### Sprint Goal

Permitir que colaboradores registrem demandas de Tecnologia de forma padronizada, garantindo o preenchimento das informações necessárias e possibilitando o acompanhamento das solicitações cadastradas.

## Definition of Done

Uma User Story será considerada concluída quando:

- a funcionalidade estiver implementada;
- os critérios de aceitação forem atendidos;
- os dados necessários forem persistidos corretamente;
- um teste básico tiver sido realizado;
- o código estiver versionado;
- a documentação relacionada estiver atualizada.
